
# N&N Engates - Site Institucional

Site premium one-page para a N&N Engates, com vitrine de categorias, produtos em destaque, formulário de contato e assistente virtual com ChatGPT.

## Tecnologias
- Front: HTML, Tailwind CSS, JavaScript Vanilla
- Back: Node.js + Express + OpenAI API
